# Windows 0.5.1 startup 500 investigation

## Symptom

A user opens Lectern 0.5.1 on Windows and sees a window titled
`zmzai agent harness` containing only `Internal Server Error`.
No affected-machine logs have been provided yet.

## Verified evidence

- Local Windows artifact: `dist/win-unpacked/resources/app.asar`, version 0.5.1.
- `node scripts/release-validation.mjs package dist/win-unpacked/resources/app.asar win32`
  passes: win32/x64, 10132 archive entries.
- Archive contains the homepage HTML, server entry, and Next route manifests.
- The standalone entry has the existing asar `process.chdir` patch.
- Release verification documents that the Windows artifact reused a macOS-built
  production frontend and was not tested on a native Windows host.
- Next 15.5.21 `dist/server/lib/router-server.js` emits this exact plain-text
  response when request handling throws and rendering the error page also throws.
  Both exceptions are written to stderr.
- Electron pipes the service stderr to `<userData>/logs/web.log`; the default
  Windows location was initially reported incorrectly as
  `%APPDATA%\Lectern\logs\web.log`. On 2026-09-08 inspection of the actual
  Windows archive showed package name `zmzai-lectern`, no top-level productName,
  and no app.setName override. The default location is
  `%APPDATA%\zmzai-lectern\logs\web.log`.
- Normal startup waits for HTTP success or 404 before opening the window.
  Consequently the screenshot alone does not establish whether this is a
  persistent initial failure, a later navigation failure, another instance's
  window, or another service on the configured port.

## Status and next step

Update 2026-09-08: logs received and cross-volume root cause confirmed. Source
fix and tests are documented in `2026-09-08-windows-cross-volume-startup.md`.
The status below records the initial investigation only.

BLOCKED on affected-machine evidence. Root cause is not confirmed. No runtime

The user was asked for the error text and stack after the last startup in

changing the runtime or packaging. Do not treat the passing archive check as
